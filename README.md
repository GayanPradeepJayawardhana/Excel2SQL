# Excel -> MySQL Converter (Offline)

Windows desktop app that converts `.xlsx / .xlsm` files into MySQL `INSERT`
statements. 100% offline - no internet, no Python needed after build.

## Features
- Drag & drop `.xlsx` onto the blue drop zone
- Excel grid preview (first 100 rows)
- Live SQL preview - updates as you type / tick options
- Table name with **Auto** suggestion + inline validation
- DROP TABLE / CREATE TABLE / BATCH INSERT toggles
- Adjustable rows per INSERT (default 500)
- Save full SQL to a `.sql` file (handles 100k+ rows)
- Built-in quick-guide panel

## Fidelity (what is and isn't changed)
- Text is stored exactly: no trimming, leading zeros (`007`), spaces, line
  breaks, tabs, backslashes, quotes, Sinhala/Tamil/emoji are all preserved.
- Numbers keep their exact digits (never `1e-05`; `5.0` stays `5`).
  Excel itself only keeps 15 significant digits.
- Dates: date-only cells -> `2024-01-05`; date+time cells -> `2024-02-01 13:45:10`.
- TRUE / FALSE are stored as the text `TRUE` / `FALSE`.
- Every row is kept in order, including blank rows between data. Only blank
  rows at the very end of the sheet are dropped. No extra id column is added.
- All columns are `LONGTEXT` with `utf8mb4`, so nothing is cut off or converted.
- Only changes MySQL forces on column names: duplicates (case-insensitive) get
  `_2`, `_3`; blank headers become `column_<letter>`; names over 64 characters
  are cut. Every such change is listed as a `-- NOTE:` comment at the top.
- Formula cells are read as the last value saved by Excel. Files generated by a
  script and never opened in Excel may have empty formula cells.

## Run from source
```bat
python -m pip install -r requirements.txt
python app.py
```

## Build the .exe (Windows)
```bat
build.bat
```
The result is `dist\Excel2MySQL.exe`.
